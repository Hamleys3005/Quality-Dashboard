How to use

  1. Export / download the latest MS Forms quality response file as .xlsx.
  2. Drag it into the box on the left, or click "Choose file".
  3. If the workbook has multiple sheets, tick the sheet(s) you want to include (monthly complaint logs are pre-selected).
  4. Use the filters to narrow by date, store, status or vendor.
  5. Nothing is uploaded anywhere — it all stays on this device for this session, unless an admin explicitly publishes it.

Publish live data to GitHub

Publishes the full loaded dataset (not just the current filter) as a JSON file committed straight to your repo, so regular viewers see it automatically on page load with no upload step. Requires a GitHub personal access token with write access to this repository's contents — use a fine-grained token scoped to only this repo. The token stays in this browser tab's memory only: it is never saved, logged, or sent anywhere except directly to api.github.com, and it is gone the moment you refresh or close the tab.
